First Place: Electronics Projects, "Smart Me" Smart Home System

+

Smart Me is an IoT-based smart home system designed to improve home safety, monitoring, and automation. It integrates multiple sensors and electronic components with a NodeMCU ESP8266 microcontroller to monitor environmental conditions, detect potential hazards, and control home appliances.

Key Features
  • Gas and smoke detection using an MQ-2 sensor with an alert system
  • Water leak detection to help prevent water-related damage
  • Temperature and humidity monitoring using a DHT sensor
  • Smart door access using a solenoid lock
  • Rain detection and notification using a rain sensor
  • Automatic and remote control of smart lighting
  • Temperature-based fan control
  • Mobile monitoring and control through the Blynk platform
  • Optional voice-control functionality for selected home devices
Technologies & Components

NodeMCU ESP8266, Arduino, Blynk IoT Platform, MQ-2 Gas Sensor, DHT11/DHT22, Water Leak Sensor, Rain Sensor, Solenoid Lock, Relay Modules, Smart Light, Smart Fan, and electronic control circuits.

Project Objective

To create an affordable and practical smart home solution that combines safety monitoring, environmental sensing, and appliance automation in one connected system.
